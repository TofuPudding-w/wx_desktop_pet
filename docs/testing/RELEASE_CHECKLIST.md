# v0.3.0 预览版检查清单

完整解压本包后执行；本清单是供用户复测的步骤，不表示所有步骤已通过。实际验证范围见 RELEASE_NOTES.md。

1. 启动：无需编辑器，出现两个角色，透明处可点击桌面。
2. 行为：走路、待机、左右边界转向和动画切换正常；长时间打字时不抢焦点。
3. 拖拽：两人均可拖动、落下；互动途中拖动能取消，随后可正常活动。
4. 互动：魏无羡在左、蓝忘机在右且距离合适时，菜单分别触发对视／拥抱；各自冷却 30 秒，另有 5 秒共同间隔。
5. 设置：暂停、自动互动、大小 100%／150%／200% 保存；重启恢复。设置 → 重置位置与检查更新可访问。
6. 隐藏：仅小兔子可见，可拖至屏幕边缘；右键菜单完整显示，显示／退出按钮均可用。
7. 帮助：离线指南可打开；网站／在线指南／反馈邮箱可访问。网络错误不影响日常活动。
8. 退出：所有窗口与进程一起关闭。快捷方式重新打开正确的版本。
9. Windows：补测 100%／125%／150% 系统缩放。macOS：尚未实机验证，仅实验用户测试。
10. 预览版不在稳定更新通道中提示；没有自动安装更新。若检查服务没有正式版本，不能把此结果理解为网络断开。
