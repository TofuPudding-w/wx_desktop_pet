## 功能

- 程序图标采用 assets/characters/icon/icon.png，Windows EXE 嵌入 16／32／48／64／128／256 像素版本，提取后与用户原图比较通过。所有原 PNG 内容保持不变。macOS 包含 .icns，仍未实机验证。
- 隐藏取消当前互动并隐藏双方，以主屏右侧 64px 白兔替代；右键显示桌宠或退出。无分钟选择、无自动返回。
- 保存与恢复暂停状态；隐藏不保存到下次启动。显示器变化时白兔重新限制到有效区域。
- Windows 可选 create-shortcut.cmd；Linux 可选 python3 create-shortcut.py。助手只在用户显式运行时创建个人桌面／应用入口；不创建服务或自动启动，也未在本机桌面执行安装。
- 互动各自冷却 30 秒，另有 5 秒共同间隔。自动／手动一致，结束／取消开始；失败且未开始的请求不计。暂停／隐藏继续计时。
- START_HERE.html 离线图文指南 + README.txt，打包时填入平台、版本、构建 ID 和冷却参数。
