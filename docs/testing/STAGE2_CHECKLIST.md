# Stage 2：日常操作菜单验收

同一工程支持 Linux／Windows，macOS 保持实验状态。版本仍为 0.2.2 开发版，不自动发布 Release。

## 操作

右键任一角色：暂停／继续、回到桌面中央、设置、互动、暂时隐藏、退出。

- 设置 → 角色大小：100%～200%，保留原始身高差；超出可用屏幕大小时限制实际尺寸。
- 设置 → 自动互动：开／关。关闭只禁止随机发起，仍可手动选择。
- 互动 → 对视／拥抱：需要魏无羡在左、蓝忘机在右、双方落地空闲、距离接近且不处于 30 秒公共冷却。按钮显示不可用原因，冷却结束自动恢复可选。暂停时请先继续活动。
- 暂时隐藏 → 1／5／15 分钟：两人同时消失，到时自动回来，保留原暂停状态。隐藏不保存到下次启动；退出进程后重开即可立即显示。当前无托盘或隐藏恢复图标。
- 大小、暂停和自动互动状态保存在 Godot 的 user://settings.cfg；正常退出重开后恢复。

## 实机检查

1. 打开每一级菜单并返回；在 100%／150%／200% 下确认菜单没有裁切，周围桌面可点击。
2. 关闭自动互动，重置位置，手动选择对视和拥抱；验证正确动画、拖拽取消及公共冷却。冷却期间留着菜单，观察倒计时结束后按钮恢复。
3. 将角色顺序颠倒、拖远、拖起或暂停，确认互动按钮显示原因，不能重复占用双方。
4. 关闭自动互动、选择一个大小、暂停；退出重开，确认三个设置恢复。再开启自动互动，继续活动。
5. 隐藏 1 分钟，确认全部角色窗口和合并拥抱窗口消失，桌面没有残留挡鼠标区域；一分钟后两人重新出现且不抢焦点。对暂停状态、互动取消后各试一次。5／15 分钟走相同代码路径；用户可按需要长测。
6. 隐藏中休眠，超过截止时间后唤醒，应恢复显示。此项需实机验证，模拟截止时间不等于休眠测试。
7. 退出关闭所有窗口和进程。

构建：`python3 tools/build_stage1.py --stage 2 --platform all`。输出 dist/stage2/<构建ID>/，不会覆盖 Stage 1 包或已有 Release。
