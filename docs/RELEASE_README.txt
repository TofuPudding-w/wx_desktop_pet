CP 双角色桌宠 v@VERSION@ · Linux x86_64

启动：解压后在文件夹中运行 ./run.sh
若解压工具丢失权限：chmod +x run.sh CPPet.x86_64
不需要安装 Godot。需要图形桌面及 OpenGL 3.3 支持。

操作：
左键按住角色拖拽，松开后落回屏幕底部。
两个角色靠近会对视、显示爱心并轮流说话，冷却 30 秒。
右键角色打开菜单：暂停/继续、回到桌面中央、退出桌宠。
再次右键同一角色收起菜单。暂停时仍可拖拽和落下。

调试：./run.sh -- --debug-window
单角色：./run.sh -- --single

环境：开发测试为 Ubuntu GNOME Wayland + XWayland，启动脚本强制使用 X11。
不支持原生 Wayland 桌宠模式；不宣称兼容所有 Linux 桌面或 Windows。
目前只在主显示器活动；角色、气泡和窗口为固定像素尺寸。
占位角色不是正式 CP 美术。对白每句最多 11 字，不支持内容编辑器。
无后台服务、无网络请求、无自启；退出菜单关闭所有角色窗口。
