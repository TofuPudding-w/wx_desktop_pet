忘羡桌宠 v@VERSION@ · Linux x86_64 · 同人非商业项目

启动：解压后在文件夹中运行 ./run.sh
若解压工具丢失权限：chmod +x run.sh CPPet.x86_64
不需要安装 Godot。需要图形桌面、X11/XWayland 与 OpenGL 3.3 支持。

左键按住人物拖拽，松开后落回屏幕底部。
右键人物打开菜单：暂停/继续、回到桌面中央、退出桌宠。
再次右键同一人物或拖起可关闭菜单；暂停时仍可拖拽、落下。
退出菜单或关闭任一角色窗口会退出整个程序。

魏无羡移动 80px/s，蓝忘机 68px/s；待机 1 FPS、走路 6 FPS。
魏无羡使用左右独立画稿；蓝忘机的走路与拖起按方向翻转。
当魏无羡在左、蓝忘机在右且相距小于 320px，双方空闲且冷却结束，
魏无羡靠近，蓝忘机等待；两人 4 FPS 对视、停留、顺序播放独立 turn_back 回身帧，再共同待机。
走路姿势在间距 200px 时结束，切换待机的同时直接到达最终站位，不滑动，最终间距 160px。
反向站位不触发对视。拖起任意一人或打开菜单会取消互动；冷却 30 秒。
首版不附加爱心或对白，不需要继续补画才能运行。

调试：./run.sh -- --debug-window
单角色：./run.sh -- --single
环境：Ubuntu GNOME Wayland + XWayland，启动脚本强制使用 X11。
原生 Wayland 桌宠模式不支持；只在主显示器活动。
固定大小；透明区域使用随帧更新的轮廓包络穿透，细小内部孔洞可能挡住下面的应用。
真实休眠恢复、混合 DPI、多显示器热插拔仍待进一步验证。
无后台服务、无网络请求、无自启、无声音。
