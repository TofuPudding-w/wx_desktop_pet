# v0.1.0 验证记录

环境：Godot 4.6.1 stable；Ubuntu 24.04 / GNOME Wayland，经 XWayland 使用 X11 后端；1920×1200；Mesa 25.2.8 / VMware SVGA3D。

## 已通过

- Godot 项目导入、脚本解析、无界面应用加载。
- 29 项状态机及内容测试：双角色预约、对白顺序、拖拽取消、视觉清理、冷却、超时恢复、暂停期间拖拽落下、负坐标显示器边界、错误 JSON 和无效数据回退。
- 同一测试中的 **模拟 7,200 秒** 压力运行：154 次完成、64 次取消，没有永久锁定。这里是模拟时间，不是实机两小时。
- 12 项应用集成测试：两个不同窗口、菜单打开、拖拽关闭菜单、暂停／继续、重置与保留冷却、菜单取消双方互动。
- XWayland 单角色 M0 窗口定位、拖拽、输入形状、空白区域穿透和焦点保持。
- **独立 release 包** 从 `/tmp` 启动：背景像素 `0x00000000`、角色像素 `0xff79b8ed`；A/B 两个窗口均接收角色点击，空白处穿透；拖拽后位置改变，键盘焦点保持；点击退出菜单后两个窗口与整个进程退出，返回码 0。
- 实际右键菜单截图已检查，中文字体和三个按钮正常显示。
- 独立包 180 秒定时退出，返回码 0；此前源代码版桌面运行超过 750 秒并完成 21 次互动（期间有鼠标操作，不算无人干预测试）。
- ZIP 完整性、可执行权限、嵌入资源、启动脚本 shell 语法、Python 工具语法、`git diff --check`。

## 尚不能宣称通过

- 连续两小时真实桌面挂机。可用 `python3 tools/soak_desktop.py` 自动执行并记录 `dist/soak-result.json`；只有 `status: passed` 才表示通过。该测试有独立日志、每 30 秒的角色状态和操作系统 RSS 采样，运行结束后自动关闭桌宠。
- 混合 DPI、多显示器热插拔、真实休眠恢复、其他显卡／桌面环境、Windows。
- 目视长时间打字不受影响：已验证焦点保持及 no-focus 属性，但没有往用户的编辑器自动输入测试文字。

鼠标探针会移动桌面指针，不要同时操作鼠标；一次扩展探针运行的 B 命中检查未通过；另一次运行两位角色均通过，但菜单点击被命中保护阻止。完整 release 基础探针曾完整通过。保留这些失败记录作为桌面自动化稳定性限制，不将后两次计为完整通过。可用 `python3 tools/desktop_smoke.py` 重现。`--preview` 模式仅截取互动窗口，不发送鼠标事件。

Godot release 模板的 `OS.get_static_memory_usage()` 可能返回 0，不能据此宣称“零内存占用”；长测工具使用进程 RSS。
