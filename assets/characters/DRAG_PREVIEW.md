# 拖起素材与交互预览

素材位置：

- `wei_wuxian/drag_up/to_the_right.png` 与 `to_the_left.png`：左右独立画稿，禁止镜像替代。
- `lan_wangji/drag_up/drag_up.png`：左右共用，向左时镜像。
- 各目录的 `DragPose.tscn` 是可复用静态姿势，`face(direction)` 选择朝向；`manifest.json` 保存原图哈希。

三张原图都是 512×683px，保持原样，不裁切、重绘或单独按人物轮廓缩放。使用与走路相同的像素缩放 `256 / 683`，因此拖起图片显示为约 191.91×256px；原图画布比走路窄，不额外放大到走路宽度。两人的拖起图本身等宽、等高，人物大小差异保持原画。画布底边中心作为定位原点。

打开 `scenes/DragPreview.tscn` 按 F6，或运行：

```bash
.tools/godot/Godot_v4.6.1-stable_linux.x86_64 --path . --display-driver x11 res://scenes/DragPreview.tscn
```

- 左键按住人物：切换拖起姿势并跟随鼠标。透明留白不命中。
- 左键松开：落回底部，恢复走路素材；落下时可以再次抓起。
- ← / →：切换两人朝向，拖动期间同样生效。
- 空格：原地播放／来回走动。初始原地播放方便点选。
- ↑ / ↓：调节移动速度；魏无羡默认 80px/s，蓝忘机 68px/s。
- 走路动画仍为 6 FPS；拖起使用静态图，不播放额外动画。
- 失去窗口焦点或鼠标已松开时释放拖拽，避免卡在拖起状态。

这是普通窗口内的素材交互预览，拖拽限定在窗口活动区。还没有接入双人互动或替换默认蓝橙桌宠，也没有将恢复走路设定为正式角色的最终状态设计。

验证：`tests/test_drag_preview.gd` 检查左右素材、透明命中、拖拽优先级、落下途中再次拖拽、停止自主移动时的落地恢复及 6 FPS 保持。
