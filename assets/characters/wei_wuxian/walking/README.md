# 魏无羡走路

用户手绘的两个独立方向，不允许水平翻转或用负 X 缩放代替另一套素材。

- `left_to_right/1.png` 至 `8.png`：向右走。
- `right_to_left/1.png` 至 `8.png`：向左走。
- 按数字顺序播放，每方向 8 帧、6 FPS，每帧 1/6 秒，一轮约 1.33 秒。
- `walking.tres` 包含两个独立动画，名称与方向目录相同。
- `Walking.tscn` 是可复用素材场景。使用 `Sprite.play("left_to_right")` 或 `Sprite.play("right_to_left")` 切换朝向，保持 `flip_h = false`。

原图保留 631×683px，不裁切、不重绘。素材场景按画布高 128px 统一缩放、以画布底边中心为原点；预览统一放大两倍到图片高 256px，使用平滑过滤。步伐中的起伏来自原画，未额外叠加上下晃动。

待机原图高 713px，走路原图高 683px；当前按各自动作的完整图片高度显示为 256px，没有按人物轮廓调大小。未来接入待机／走路切换时，需要检查人物大小与脚底是否自然衔接。

打开 `scenes/WalkingPreview.tscn` 按 F6，或在项目根目录运行：

```bash
.tools/godot/Godot_v4.6.1-stable_linux.x86_64 --path . --display-driver x11 res://scenes/WalkingPreview.tscn
```

预览现在显示忘羡两人一起走动，默认 80px/s。↑ / ↓ 调速度，← / → 切朝向，空格切换原地播放。两人的原图宽度同为 631px，统一等比显示宽度约 236.5px；蓝忘机原图更高，显示高度也自然更高，不按人物轮廓或画布高度强制等高。蓝忘机使用可镜像的单组帧，魏无羡保持独立双方向。移动速度仍是预览参数，不是最终桌宠定稿。
