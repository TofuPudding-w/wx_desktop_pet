# 拥抱 · 本地试作（未发布）

四张 1024×713 的合并画稿，原图未修改。固定魏无羡在左、蓝忘机在右；不镜像。

第 1 帧中的两人分别等于独立 idle/01.png 向右平移 78px、504px，所有非透明像素匹配。按现有 256/713 缩放，两人脚点距离为 147.568px。靠近时走路提前 40px 结束，同一次更新直接到最终站位；随后切换合并图。

时长：第 1、2 帧各 1/6 秒（6 FPS），第 3、4 帧各 1/2 秒（2 FPS），顺序为 1 → 2 → (3 → 4) × 3 → 独立待机，总长约 3.333 秒。结束后直接恢复独立待机，不播放回程帧。重复次数由 data/interactions.json 中 hug.hold_repeats 控制。

## 预览

```bash
.tools/godot/Godot_v4.6.1-stable_linux.x86_64 --path . --display-driver x11 scenes/HugPreview.tscn
```

空格：靠近并重播；1：独立待机；2：合并首帧对照；Esc：关闭。

## 桌面试用

```bash
./run.sh -- --hug-demo
```

试用参数只选择拥抱；正常 `./run.sh` 会在拥抱和对视之间按权重抽取。两人须在正确左右站位、落地、距离小于 320px 且空闲；结束或取消后双方互动共享 30 秒冷却。右键菜单、暂停、拖拽任意一方均可中断。合并期间点击画面左半侧对应魏无羡，右半侧对应蓝忘机（按两人脚点中点划分）。

合并图使用临时透明窗口；普通角色只暂时隐藏画稿并关闭命中，结束／取消后恢复。原有两角色逻辑与独立行走继续复用。

工程版本号与已导出的 v0.2.2 不变。此功能仅在源码启动中可用，未打包、打标签、提交或上传新 Release。
