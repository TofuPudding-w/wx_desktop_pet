# 忘羡桌宠 v0.3.0 · 首个公开预览版

作者手绘的魏无羡与蓝忘机，一起住进你的桌面。同人作品，非官方、非商业，仅供爱好者个人使用。

## 可以做什么

- 两个角色独立待机、行走；左键拖起，松开落回底部。
- 自动或手动触发对视、拥抱；拖动可取消互动。两人需魏无羡在左、蓝忘机在右，距离合适且未暂停。
- 对视与拥抱各自冷却 30 秒，另有 5 秒共同间隔；自动／手动规则一致。
- 设置：角色大小 100–200%、自动互动、重置位置和手动检查更新。大小、暂停及自动互动会保存。
- 隐藏后留下可拖动的小兔子，右键选择显示或退出。没有倒计时。
- 重新设计的中英文菜单、完整显示的隐藏菜单、离线图文指南、官网与反馈入口。
- Windows／Linux 提供可选快捷方式助手；不会自动创建桌面入口。

## 开始使用

完整解压 ZIP，先看 START_HERE.html。Linux 运行 ./run.sh；Windows 双击 CPPet.exe 或 run.cmd；macOS 保留整套解压目录并打开 .app。无需 Godot 编辑器。

右键角色 → 设置／互动／帮助。右键小兔子 → 显示桌宠或退出。菜单帮助 → 使用指南提供离线与在线入口。
