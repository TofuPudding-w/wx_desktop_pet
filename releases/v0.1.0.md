# CP 桌宠 v0.1.0 · Linux 原型预发布

同人作品，非商业，仅供爱好者个人使用。本版本使用代码绘制的占位角色，不包含正式 CP 美术。

## 本版内容

- 双角色透明、无边框、置顶窗口；空白区域允许鼠标点击穿透。
- 待机、行走、拖拽、松手落下，以及一次双人对视、爱心和轮流中文对白。
- 右键菜单：暂停／继续、重置位置、退出整个程序。
- 内置中文字体；无需安装 Godot。

## 下载与运行

当前仅提供 **Linux x86_64** 包：`CPPet-v0.1.0-Linux-x64.zip`。
Windows 和 macOS 尚未适配／验收，本版不提供这两个平台的安装包。

解压 ZIP，进入文件夹运行 `./run.sh`。若解压后缺少权限，执行 `chmod +x run.sh CPPet.x86_64`。
脚本强制使用 X11；在 GNOME Wayland 会话中需要 XWayland。
下载旁边的 `.zip.sha256` 文件，在同一目录执行：

```bash
sha256sum -c CPPet-v0.1.0-Linux-x64.zip.sha256
```

GitHub 自动附带的 Source code 文件是源码，不是可直接运行的桌宠。
