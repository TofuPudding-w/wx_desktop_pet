LATEST NOTES

A little more, with each update.

  • First public preview: independent walking, dragging, eye contact, and hugs.
  • Pet size and automatic interaction settings, plus a draggable rabbit for hidden mode.
  • Chinese/English menus, an offline guide, website and feedback links, and manual checks for stable updates.
  • Windows and Linux downloads are available. macOS is experimental and has not been tested on a physical Mac.

To update, close the old app, extract the new version, and check that it works before deleting the old folder. Recreate shortcuts if you move the folder. Updates are currently downloaded manually.
