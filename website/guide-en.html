01 / First launch

Windows
  1. Extract the entire ZIP to a folder you intend to keep.
  2. Double-click CPPet.exe or run.cmd. Keep CPPet.pck beside the EXE.
  3. Want a desktop shortcut? Run create-shortcut.cmdto create a shortcut with the two-rabbit icon.

You do not need Godot or administrator privileges. Run the shortcut helper again after moving or updating the app folder.

Linux / Ubuntu
  1. Extract everything, then run this inside the folder: ./run.sh.
  2. If you get a permission error, run chmod +x run.sh CPPet.x86_64 and try again.
  3. For a desktop or application-menu shortcut, run python3 create-shortcut.py. If GNOME asks, right-click the shortcut and choose Allow Launching.

The supported desktop backend is X11, including XWayland under GNOME Wayland. The launcher selects X11.

macOS (experimental)

Extract the archive, then open the .app. In Finder, use Make Alias and move the alias to your desktop.

This platform has not been tested on a physical Mac. The app is not notarized and macOS may block it. Do not disable system-wide security protections to run it. Correct operation on macOS is not guaranteed.

02 / Point at a character

Dragging and right-clicking

Hold the left mouse button on a character to drag them. Release to let them return to the bottom. Right-click either character to open the menu.

The menu lets you pause/resume, reset positions, resize, choose interactions, hide, or exit. Reopen this page through Right-click → Help → User guide → Offline guide.

Make yourself comfortable

Settings → Pet size: 100%, 125%, 150%, 175%, or 200%. Actual size is limited on smaller screens.

Settings → Automatic interactions: turn this off to trigger interactions manually only.

Settings → Menu colors: choose background or text, adjust the color wheel, preview, then select Apply and save. Cancel leaves your current colors unchanged. Restore defaults and apply to return to the original light theme. The rabbit menu uses the same colors.

Colors, size, pause, and automatic interaction preferences are saved. Resizing preserves animation frame rates and the characters' relative heights.

03 / How do interactions work?

Place Wei Wuxian on the left and Lan Wangji on the right, both on the ground and close together.The current artwork supports this orientation only. Both characters must be idle or walking, with activity unpaused. The interaction menu explains when their positions are unsuitable.

Automatic interactions

When automatic interactions are enabled and conditions are met, an available interaction is selected randomly. Interactions on cooldown are excluded.

Choose an interaction

Right-click a character → Interactions → Eye contact / Hug. Manual triggers follow the same position, availability, rest, and cooldown rules and will not interrupt another interaction.

InteractionCooldown for the same interactionShared rest between interactions
Eye contact30 seconds5 seconds
Hug30 seconds
  • Each interaction has its own cooldown.A hug does not put eye contact on a 30-second cooldown, and vice versa.
  • Automatic and manual triggers use the same timers, starting when the interaction finishes or is canceled.
  • Dragging, opening a menu, pausing, hiding, resetting positions, or resizing cancels the current interaction, starts its cooldown, and starts the shared rest period.
  • Requests that cannot start do not trigger cooldowns.
  • Cooldowns continue while paused, in menus, or hidden. Automatic interactions wait until activity resumes. Restarting the app resets the session's cooldown records.

For example, after a hug, eye contact can start after 5 seconds if its own cooldown is clear and positions are suitable. Another hug requires 30 seconds. Buttons show cooldown or rest countdowns.

04 / A quieter desktop

Right-click a character → Hide pets

Both pets disappear, leaving this rabbit at the screen's right edge. There is no countdown or automatic return. Left-drag the rabbit anywhere on the primary screen; its position is remembered for this session.

Right-click the rabbit → Show petsto bring both pets back with their previous pause state. You can also choose Exit pets from the rabbit menu.

Bubble dialogue

Right-click a character → Tools → Bubble dialogue

Create and name a script. Use + to add a line, select Wei Wuxian or Lan Wangji, enter the text and display duration. Reorder with ↑ / ↓ and remove the current line with −. Each line allows up to 160 characters and 4 line breaks, displayed for 1–60 seconds. A script can contain up to 200 lines.

Edits save automatically; you can also select Save. Scripts can be copied or deleted. Play holds both pets idle while their bubbles appear in sequence. Pause/Resume controls playback; Stop restores their previous activity state. Closing the editor does not stop playback. Reopen it from Tools. Edits made during playback take effect when you restart playback.

Dragging, hiding, resetting positions, resizing, or changing the pets' pause state stops dialogue. Bubbles are click-through. This feature works offline and never uploads scripts. Scripts are stored in stories/library.json in the local Godot user data directory, with a .bak copy of the previous save. Back up both files before switching computers.

05 / Daily alarm

Right-click a character → Tools → Daily alarm

Choose an hour and minute in 24-hour format, then Enable daily alarm. It reminds you once a day using your computer's local time. If today's time has passed, it starts tomorrow. The window shows the next reminder date. There is one alarm; both pets open the same window.

The enabled state and time are saved across restarts. Closing the window, pausing, or hiding the pets does not disable the alarm. A reminder appears without taking keyboard focus, with an optional short chime. Got it dismisses today's reminder; tomorrow's remains scheduled. Disable alarm stops daily reminders. Change time disables the alarm before editing.

The alarm cannot run while the pet app is closed, and missed reminders are not replayed after restarting. It does not wake a sleeping computer. If the app remained running, missed reminders are combined into one after waking. The alarm follows local date and time, with at most one reminder per local date.

06 / Troubleshooting

How do I exit? Why are the pets still after restarting?

Right-click a pet or the rabbit and choose Exit pets. Pause state is saved: if the characters are still, choose Resume activity. Avoid running multiple copies at once.

Why are interaction buttons disabled, or nothing happens?

Check the reason shown beside the button. Wei Wuxian must be left of Lan Wangji, both nearby and on the ground, with activity unpaused. Automatic mode also needs Automatic interactions enabled. Buttons update when cooldowns and rest periods end; you do not need to reopen the menu.

Are the pets too small or large? Is a shortcut broken?

Use the pet's size settings first; operating-system display scaling affects the whole desktop. Moving the extracted folder breaks old shortcuts. Run the included shortcut helper again.

How do I report a problem?

Include the OS version, display scaling, pet size, steps to reproduce, and expected versus actual behavior. On Windows, run diagnose.cmdand collect the files at the location shown in its window: pet.log and telemetry.json. Review logs before sending them.

Detailed test steps are in the package's TEST_CHECKLIST.md. Include the build ID at the bottom of this page in your report.
